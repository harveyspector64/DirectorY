# Mid-Wilshire Mayhem

A playable top-down GTA2-style sandbox set in a stylized Mid-Wilshire / Los Angeles map.

## Features
- On-foot traversal + sprint
- Enter / exit vehicle gameplay
- Drivable player car with boost + handbrake feel
- Ambient civilian traffic and pedestrians
- Police chase + wanted star escalation system
- HUD with zone readout, status, controls legend, interaction prompt, and minimap
- Built as a zero-build static web app (works from any simple local server)

## Run
```bash
python -m http.server 4173
```
Then open: `http://localhost:4173`
