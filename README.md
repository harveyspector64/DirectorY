# Mid-Wilshire Mayhem

A stylized top-down Three.js action sandbox inspired by GTA 2, set in Mid-Wilshire Los Angeles.

## Features
- On-foot traversal and sprinting
- Enter/exit player vehicle with arcade handling
- Civilian traffic + pedestrians
- Police chase/wanted system with siren audio tones
- HUD with zone display, status, wanted stars, controls, and minimap
- Procedural city blocks with roads/buildings/trees

## Run
```bash
python -m http.server 4173
```
Open `http://localhost:4173` in a browser.
